# Nivora — Django Blog Platform

A full-featured blog platform built with Python and Django.

**Nivora** is a modern blog platform developed to provide users with an interactive environment for publishing and engaging with content.

## Features

* User registration and authentication
* Email sending
* Image upload
* Create, edit, and delete posts
* Comment system
* Like system
* Save/bookmark posts
* User profiles
* Django Admin Panel
* Responsive design

## Technologies

* Python
* Django
* HTML5
* CSS3
* JavaScript
* SQLite / PostgreSQL

## Project Overview

**Nivora** is a full-featured blog platform developed with Django.

Users can create accounts and interact with blog posts through comments, likes, and saved posts. The platform also supports image uploads and email functionality.

The main goal of this project was to practice building a complete web application with Django and implement features commonly used in real-world projects.

## Installation

### Clone the repository

```bash
git clone https://github.com/Pfe1010/Nivora.git
cd Nivora
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Apply migrations

```bash
python manage.py migrate
```

### Create a superuser

```bash
python manage.py createsuperuser
```

### Run the development server

```bash
python manage.py runserver
```

Then open:

```text
http://127.0.0.1:8000/
```
